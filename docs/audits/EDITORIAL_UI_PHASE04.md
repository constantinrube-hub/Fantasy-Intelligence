# Editorial Phase 4 — Portfolio and League Home

Isolated `ui/editorial-p04-overviews`, parent user-approved Phase 3 `cdc7029c`.
No merge/production release or model/promotion/workflow authority is added.

Portfolio replaces repeated rank cards with one searchable league table. Basic
shows league, format, provider/config lifecycle and next review. Expand shows
cached result/tasks/concerns and timestamp scope; Advanced keeps exact namespace,
research coverage and the original cached browser snapshot. Cached heuristic
recommendations are rewritten as review navigation, never TAKE/CLAIM commands.
Disabled, archived and explicit eliminated/data-only entries remain reportable,
with retained-evidence navigation and no Set lineup prompt. Chopped survival is
unverified unless an authoritative lifecycle source explicitly supplies it.

Observed future draft start and roster-game times may appear as timing context;
these are not inferred waiver deadlines or verified lineup-lock policies.

Counts distinguish saved/configured entries, retained entries and the actual
historical_research status field. Exposure opens only on request, counts unique
canonical provider player IDs once per known managed roster, and shows the known
snapshot denominator plus missing coverage. Unknown ownership is not zero;
selected opponent rosters cannot impersonate managed ownership. These are cached
loaded ownership observations, not contemporaneous portfolio or starter exposure.

Home shows a prior regular-season reported result and concise review tasks, with
roster selection forwarded to the existing roster-control owner. The read-only
Weekly summary shares its timing, result cache and provider path. It does not
reconstruct forecasts, impute missing scores or declare Chopped survival. Expand
shows submitted player actuals; full evidence links back to Weekly. Position
strength remains collapsed, named and owned by original teamPowerMetrics.

League and portfolio reports show existing Window 1D capture summaries served by
the Phase 3 reporting adapter. Coverage, captured time, source hashes and research
status stay explicit; a capture/green workflow does not confer activation.
Phase 6 remains the owner of the full global report/research document library.

Existing league loader, light status refresh, model/legality calculations and
canonical routes remain owners. Async results are league/season/roster guarded;
context changes close disclosures. Local overview cache has a separate name and
never changes research artifacts. Public build serves no personal waiver reports.

Validation includes lifecycle/identity/null semantics, populated mobile/desktop
review and stale result handling, prior Weekly/Waiver regressions, frozen shell
comparison, and deterministic source/dist release gate.
