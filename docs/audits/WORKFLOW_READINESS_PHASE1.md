## Implemented behavior

1. Blank target weeks resolve from a fetched or explicit nflverse regular-season schedule, not the modal stored snapshot week or a separate Sleeper state default. Both producers use the same resolver.
2. The operational week ends at Eastern midnight after its last scheduled game day; advancement additionally requires observed final result/score fields. A late or unresolved prior game blocks automatic advancement. First kickoff does not end the week.
3. The resolver uses timezone conversion across DST and requires all 18 regular-season weeks. Missing/truncated/wrong-season schedules and post-season inference fail closed. Explicit historical weeks require no schedule fetch. An expanded future season must update this operational contract alongside the shared calendar.
4. January closeout resolves to the preceding NFL season. Workflow dispatch can override season/week; automatic runs no longer hardcode 2026.
5. Snapshot/profile/current/app scoring mismatches retain blockers. A week-mismatched Weekly Actions league row identifies the requested week and separately records the observed input week.
   Window 1D now independently validates live state with the same canonical research contract used by Current Snapshot. Waiver timing changes and omitted-versus-zero `best_ball` no longer falsely invalidate historical research. Recognized roster evolution or passive reserve growth cannot bypass simultaneous scoring or other research-contract changes. Full structural fingerprints remain diagnostics; live budget/adds guards remain in the existing planner.
6. Readiness metadata includes profile and snapshot hashes, scoring signatures, source errors, input week/time, snapshot age, global eligible-row counts and model-position coverage where hydrated inputs exist.
7. Summaries separate ready, partial, blocked, not-applicable and unknown results. Lineup capability and execution context remain separate from waiver capability. Not-applicable or unknown reports are not counted as ready.
8. Each workflow summarizes the exact output generated by that invocation and commits its resolved season directory. An unrelated report with a newer filesystem timestamp cannot be selected.
9. A green workflow can still preserve a blocked research report or useful raw waiver history. The artifact summary states its evidence status explicitly; collection is not falsely promoted to a usable recommendation.
