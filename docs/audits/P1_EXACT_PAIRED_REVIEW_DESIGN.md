# Exact paired forecast review — 2026-10-11

## Authority and scope

The user requested uninterrupted P1–P3 implementation with local phase branches.
This design is documented before implementation. The historical model-switch
pause in CODEX_MODEL_ROUTING is superseded by that instruction for this run;
it grants no model promotion or production statistical adjustment authority.
M9 remains champion. This owner measures stored forecasts, never refits them.

## Strict baseline replay

Use the frozen Sleeper archive already bound by weekly_pr2_baseline_archive.
Every relevant nonzero scoring key must have an explicitly supported linear
statistic and a finite value. Unknown keys, nonlinear bonus/bucket scoring,
pre-scored fallback points, absent raw inputs and conflicting aliases block
certification. Do not interpret omission as zero. TE reception bonuses use
receptions only for TE. Irrelevant position-specific keys are recorded.
This conservative initial contract can exclude a correct forecast; it cannot
certify an incompletely scored one. Production scoring is unchanged.

## Cohorts and metrics

Descriptive metrics use all finite paired rows from the replayed outcome owner.
The exact cohort additionally requires archive source receipt, complete strict
scoring, reproduction of the captured mean, bound FIE artifacts, declared FIE
model identity and active governed FIE forecast. Exact league outcomes come
only from the existing PR2 source→adapter→scoring→evaluation replay.
No old capture is amended to manufacture missing receipts.

Report MAE, RMSE, signed prediction bias, median absolute error and paired
absolute-error difference (FIE minus Sleeper). Spearman uses average ranks for
ties and is null for constant or fewer than two observations. Slice by
position, league/scoring signature, week and model identity. No p-values or
superiority claims: league-player observations repeat players and share games.
No cross-signature raw-point aggregate is presented as universal model skill.
Missing intervals stay missing; no interval calibration is inferred from means.
Selection counts and rejection reasons accompany the exact cohort. Per-row
certification concerns baseline scoring, not provider truth or promotion.

## Acceptance

Tests cover missing input versus explicit zero, negative weights, alias
conflicts, position relevance, unsupported bonus scoring, nonfinite values,
known numerical metric examples, tied ranks, independent source/model gates,
and archive tampering. Weekly review includes both descriptive and exact
cohorts after its existing immutable replay checks. Every output is research
only; historical cohorts may legitimately contain zero exact pairs.
