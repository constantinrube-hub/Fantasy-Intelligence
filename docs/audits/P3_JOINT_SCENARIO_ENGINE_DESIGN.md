# P3 joint scenarios, opponents and draft boundary — 2026-10-11

## Authority

Documented before implementation under the user's overnight instruction.
Research tools only. M9, current projections, managed PR2 decisions, runtime
workers and transaction gates retain their established authority.
No arbitrary Gaussian distributions, calibration approval or model promotion.

## Bank and calibration

A bank is an immutable, content-bound set of complete joint weekly point
vectors with canonical IDs, exact scoring signature, model/version, generated
time, target and first kickoff. Every vector contains the same player universe.
One sampled index is shared by every lineup and opponent: covariance and
overlap are preserved as supplied, never independently reshuffled. Uniform
finite scenarios initially; nonuniform weights are unsupported and rejected.
Bank construction and football correlation estimation require separate future
validated research. Absent bank/calibration evidence blocks the adapter.

A calibration diagnostic uses an independent, frozen holdout set with stored
pregame point samples, exact-scored outcomes and source/time bindings. Report
central 80% interval coverage, mean error and interval width per position and
scoring signature. Training ends before the first holdout forecast, forecast
precedes kickoff, and outcomes precede the target-bank cutoff. Repeated
league/player/week rows are not independent validation. Diagnostics grant no
governed approval; engine outputs stay explicitly research conditional
probabilities. All input files are rehashed; a declared approved status cannot
activate production. Existing means alone do not create a calibrated bank.

## Consumers

Managed lineups are fixed ex ante and checked by the established exact legal
assignment owner. All selected players must fill exactly the declared slots;
no per-scenario managed reoptimization. Best ball is separately declared and
optimizes legally inside each vector. Floor/median/ceiling use empirical
quantiles of lineup totals, not sums of individual quantiles. Direct H2H
returns win/tie/loss separately, with opponent submitted versus assumed lineup
origin exposed. Chopped consumes the complete active field, elimination count
and an explicit tie policy. Equal random elimination within a cutoff tie is
supported only when the caller declares that rule; unknown rules block.

Exhaustive mode enumerates the bank exactly. Sampled mode uses a fixed seed
and reports draws, bank size and conditional sampling error. That error does
not represent model uncertainty. Comparing lineup A/B uses the same scenario
indices. A same-signature portfolio sum is supported; mixed-signature portfolio
and remaining-season outcomes require a future multi-profile/joint bank.
Late-news/availability uncertainty must exist in the supplied bank; no invented
injury odds. Live Monday-night conditioning is not implemented by pregame banks.

## FAAB and draft

Bid curves use complete captured competing bids, observation cutoffs, scoped
league/currency budgets and explicit tie policy. Winner-only records are
insufficient to reconstruct rival maxima. Return empirical acquisition odds,
sample size and budget feasibility; no smoothed manager labels or economically
optimal bid from tiny samples. Survival gain can be compared with that curve,
but multiplying unrelated acquisition and football probabilities is not
authorized. A validated joint market/field model and remaining-season reserve
utility are still needed for production chopped FAAB optimization.

Draft review checks a frozen same-signature player pool, roster/slot and pick
state. It reports available candidates and conditional marginal best-legal
roster score over the same joint vectors. This is structural roster research,
not an ADP replacement or managed weekly recommendation. A complete roster's
best-lineup outcome distribution is retrospective automatic selection; label
it distinctly from fixed managed lineups. Future board/run probabilities,
keepers, dynasty values and 3RR order must come from their own governed owners;
unknown constraints block actionable picks. Existing draft worker hardening
does not validate these new probability models.

## Acceptance

Deterministic replay, sample seed, correlated synthetic cases, ties, overlapping
players, illegal/duplicate lineups, negative outcomes, incomplete field,
nonfinite inputs, source/hash/time/target drift, missing calibration and
winner-only auction records are tested. Synthetic fixtures prove mechanics
only. No synthetic bank is saved as real calibrated football evidence.
