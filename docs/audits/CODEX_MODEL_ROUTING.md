# Codex Model Routing

This repository follows the user-approved model-routing policy for the audit.

## Default

Use GPT-5.6 Terra at High reasoning for normal audit implementation, lifecycle/workflow reconciliation, known-target refactors, integrity tests, regression fixes with a clear cause, and release synchronization.

Use Luna optionally for low-risk mechanical work; do not interrupt a productive Terra session solely to downgrade.

## Required escalation

Before a new football-model architecture, statistical methodology, unknown systemic regression, research-completeness scoring, cross-model consistency reasoning, injury/IDP/opponent-interaction methodology, or waiver-economics design, stop at a clean boundary and emit exactly:

`MODEL_SWITCH_REQUIRED: GPT-5.6 Sol — High`

Return to Terra after the Sol-only design or reasoning result is documented and committed. Do not use Sol for routine CI, documentation, generated synchronization, or known-target refactors.
