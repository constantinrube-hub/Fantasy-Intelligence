# FIE V9.3.2 Browser QA & Ranking Integrity

## Release objective

V9.3.2 is the browser-QA completion release for the V9.3 decision UX consolidation. It does not introduce a new research milestone. It makes the runtime faithfully consume the existing governed research, Sleeper baselines and league context without converting missing data into zero, using incompatible profile fingerprints, or allowing separate UI surfaces to invent conflicting player rankings.

## Root causes addressed

### Nullable numeric coercion
JavaScript's `Number(null) === 0` and `Number("") === 0` caused missing weekly projections, ranges, special-teams values and optional roster caps to become real zeroes. V9.3.2 centralizes strict nullable numeric parsing.

### Season zero
A blank season control could similarly become numeric 0. The loaded Sleeper league season is now authoritative. Blank/zero UI values are invalid selectors, not seasons.

### Structural fingerprint drift
Stored league profiles use the structural-v2 contract, but the current-snapshot builder rebuilt the live fingerprint from the complete mutable Sleeper settings object. V9.3.2 uses the exact same `structural_contract()` in both paths. The captured-live regression matches 19/19 managed leagues.

### Competing ranking kernels
Draft Board, Value Finder and Draft Assistant could expose different notions of "FIE rank". The canonical Draft Base Value service now owns roster-neutral player-quality and positional ranking. Value Finder compares that rank to market; Draft Assistant adds roster/timing effects after the common base.

### UI panel ownership
The Matchup panel was dynamically created outside the V9.3 panel list and could survive navigation. SurfaceRouter now owns panel transitions and cleanup.

### Missing transaction identity helper
League Intel referenced an undefined Sleeper-ID-to-position helper. Canonical PlayerIdentity now owns this lookup.

## Canonical contracts

### Numeric
- null / undefined / blank => unavailable
- 0 / "0" => legitimate zero
- invalid numeric => unavailable

### Weekly projection
1. governed FIE current projection
2. direct governed weekly projection
3. Sleeper weekly projection
4. explicitly labelled estimate fallback
5. unavailable

A verified bye is a valid zero and is separately labelled BYE.

### Season
Loaded `state.league.season` is authoritative when valid. A UI season selector can override only with a valid NFL-like positive season value; blank and 0 never replace a loaded 2026 league.

### Canonical draft value
Draft Board/Players/Value Finder/Assistant share the same roster-neutral player-quality rank. Market does not influence that FIE rank. Value Finder and Draft Assistant layer context after it.

## Workflow after upload

1. Run **Validate FIE V9.3.2 Browser QA**.
   - Required: `STATUS: DEPLOYABLE_SOURCE`.
2. Run **Refresh FIE Current Season** with League ID, Season and Week blank; Governance mode `KEEP`.
   - This regenerates all enabled managed-league current snapshots against live Sleeper using the corrected structural fingerprint contract.
3. Run **Validate FIE V9.3.2 Browser QA** again.
   - Required: `STATUS: DEPLOYABLE_SOURCE` against the freshly committed current store.
4. Allow Cloudflare Pages to deploy the resulting `main` commit and complete the browser acceptance list below.

Do not rebuild M1-M6 by default. Only run targeted historical research for a league that still reports a real structural/profile mismatch after the corrected current refresh.

## Browser acceptance checklist

### Genesis Dynasty
- Weekly shows Season 2026, never Season 0.
- Non-bye stars have nonzero/fallback weekly projections when a baseline is available.
- K and D/ST render without fabricated 0/0 ranges.
- Week 1-18 selectors work and row clicks open the detail drawer.
- `C0nstant1n` remains the preferred roster.

### Chopped Drive
- Draft ranks are credible enough for audit and player rows expose rank lineage.
- Value Finder opens and canonical FIE positional ranks match Draft Board for the same player/context.
- Waivers are Add -> Drop transactions and are not empty because of false zero caps.
- Matchup panel does not remain visible after leaving Weekly.

### Draft Assistant
- Best Pick, Alternative and Value Play cards are visible when draft state is available.
- Drafted players disappear from Value Finder/Assistant after draft synchronization.
- Board-to-Decision movements are explainable through roster/timing components.

### Best Ball
- Ceiling/Profile is explained in the drawer.
- Tier 1 does not expand into a semantically useless 70-player tier.
- Draft Assistant Portfolio Fit remains explicitly heuristic.

### Trade / League Intel
- Unset experience limits are unlimited, not `/0` constraints.
- Transaction history loads without `playerPosBySleeperId` ReferenceError.
