# Historical Documentation Archive

This archive preserves historical implementation and release evidence without presenting it as current operating guidance.

- [`implementation/`](implementation/) contains applied patches, implementation notes, upload instructions, and version-specific repair records.
- [`releases/`](releases/) contains historical release notes and deployment-era release records.

Current operational guidance is in [`../current/README.md`](../current/README.md). Four historical records remain at their original paths because preserved patch or checksum manifests require those exact paths: `APPLY_INSTRUCTIONS.md`, `APPLY_V975.md`, `RELEASE_NOTES_V9.3.4A3.md`, and `docs/current/V9.3.4A3-SCORE-FIX.md`.

The complete relocation inventory and preservation rationale are in [`../audits/TRANCHE5D_DOCUMENTATION_CLEANUP_PREFLIGHT.md`](../audits/TRANCHE5D_DOCUMENTATION_CLEANUP_PREFLIGHT.md).
