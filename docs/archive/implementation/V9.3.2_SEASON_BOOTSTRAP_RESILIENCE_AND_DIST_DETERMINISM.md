# V9.3.2 Season Bootstrap Resilience and Dist Determinism Hotfix

## Trigger

Two browser/release issues remained after the V9.3.2 season-scope and deployment-sync fixes:

1. The live app could fail during `buildPlayerUniverse()` with `FIE season context is unavailable` even though the helper file existed in the committed deployment tree.
2. A successful deploy-dist run could be followed by a failed validator reporting only `M dist/config/build-manifest.json`.

## Root cause A: hard dependency on one startup asset

The early global `activeSeason()` binding correctly existed before `buildPlayerUniverse()`, but it threw when `window.FIESeasonContext` was absent. This made the entire league load depend on a tiny external helper having executed successfully before the first inline application script. The helper exists in source and dist, but browser/edge cache or asset delivery state could still make that assumption fail.

### Repair

- Keep `app/core/season-context.js` as the canonical implementation.
- Request it using an absolute cache-busted URL.
- Before defining `activeSeason()`, install an equivalent strict bootstrap API only when the canonical external helper is absent.
- Never throw merely because the external helper is unavailable.
- Preserve loaded Sleeper league season as the first-priority source.

This is fail-soft for delivery, not fail-open for semantics: invalid blank/zero seasons are still rejected.

## Root cause B: nondeterministic build manifest

`research/build_app_manifest.py` previously assigned `generated_at` from `datetime.now(timezone.utc)`. Therefore two builds of identical source necessarily produced different manifests, and the validation workflow correctly saw committed `dist/` as stale every time.

### Repair

`generated_at` now comes from the immutable `config/release.json -> built_at` value. A dedicated integrity test rebuilds the manifest twice and requires stable output metadata.

## Regression coverage

The season runtime test now covers both paths:

- canonical external service present;
- canonical external service deliberately absent.

In both paths a loaded Sleeper 2026 league must resolve to Season 2026, and selector values blank/0 must not override it.

The deterministic-build test is part of `research/release_gate.py`.

## Validation result

`python tools/release_build.py --mode personal` completed with `STATUS: DEPLOYABLE_SOURCE` after this hotfix. Current-storage integrity covers 19 leagues and the corrected structural-profile regression remains 19/19.
